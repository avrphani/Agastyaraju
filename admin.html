Agastyaraju Admin Panel

One-time Setup

How to get your GitHub Token:

1. Go to github.com → Settings → Developer Settings → Personal Access Tokens → Fine-grained tokens

2. Create a new token with Contents: Read and write access on the Agastyaraju repository.


How to get your Netlify Deploy Hook (enables instant website updates):

1. Go to Netlify → agastyaraju → Site settings → Build & deploy → Build hooks

2. Click Add build hook, name it "Admin Panel", copy the URL and paste it above.

⚠ GitHub token not set You can view and edit products below, but you won't be able to publish until you add your GitHub token. Click ⚙ Settings above.
